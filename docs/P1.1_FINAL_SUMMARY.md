## Key Changes Applied:

### 1. Imports
```python
from decimal import Decimal
from sqlalchemy import Numeric  # for SQLModel fields
```

### 2. Type Conversions
- `float` → `Decimal`
- `float | None` → `Decimal | None`
- `Optional[float]` → `Optional[Decimal]`

### 3. Database Fields (SQLModel)
```python
# Pattern for financial fields in database models:
field_name: Decimal = Field(
    default=Decimal("0"),  # or None
    sa_column=Column(Numeric(precision=18, scale=6))
)
```

### 4. Broker Mapper Conversions
```python
# Pattern for incoming floats from APIs:
Decimal(str(value))  # NOT Decimal(float_value)
```

### 5. Default Values
```python
# Old: peak_mtm: float = 0.0
# New: peak_mtm: Decimal = field(default_factory=lambda: Decimal("0"))

# Or in Pydantic:
# Old: amount: float = Field(default=10000.0)
# New: amount: Decimal = Field(default=Decimal("10000"))
```
