## Changes Made:

### 1. Import Decimal (all files)
```python
from decimal import Decimal
```

### 2. Type Changes (Pydantic Models & Dataclasses)
All financial fields changed from `float` to `Decimal`:
- Price fields: `price`, `stop_price`, `ltp`, `avg_price`, `net_avg_price`
- P&L fields: `realized_pnl`, `unrealized_pnl`, `total_pnl`
- Margin fields: `initial_margin`, `maintenance_margin`, `available_margin`, `utilized_margin`
- Exposure fields: `total_equity`, `cash_balance`, `max_instrument_exposure`, etc.
- Position fields: `mtm`, `drawdown`, `market_value`, etc.

### 3. SQLModel Database Changes
For models.py (RiskConfigOverride):
```python
sa_column=Column(Numeric(precision=18, scale=6))
```
Applied to all float → Decimal fields for database storage.

### 4. Broker Mapper Changes
Conversion pattern for incoming floats from API:
```python
# OLD: float(item.get("price"))
# NEW: Decimal(str(item.get("price")))
```
Used for all Fyers and Paper broker mappers.

### 5. Default Values
Changed all default float values:
```python
# OLD: peak_mtm: float = 0.0
# NEW: peak_mtm: Decimal = field(default_factory=lambda: Decimal("0"))
```
